# Text-to-SQL AI Assistant 🤖

Welcome! This assistant translates your natural language questions into SQL queries, executes them against your SQLite database, and presents clean answers and data tables.

### 💡 Capabilities
- **Natural Language Data Queries**: Ask questions about sales, products, orders, reviews, or customers.
- **Ambiguity Detection & Clarification**: Prompts for clarification when queries are ambiguous.
- **Database Schema Exploration**: Browse tables and column definitions with one click.
- **Collapsible Tool Steps**: Inspect the exact SQL query executed under the hood.

Select a starter below or ask any question to get started!
